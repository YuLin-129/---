# 輸出

可以直接匯入 RP Engine（也相容酒館）的檔案。這些檔案都是由 [`工具/`](../工具/) 從總表產生的，不要手改；要改請改來源再重新產生（見 [`世界書/README.md`](../世界書/README.md)）。

| 檔案 | 內容 | 匯入位置 |
| --- | --- | --- |
| [`魔都精兵日常.json`](魔都精兵日常.json) | 旁白卡（去主角化的日常，從橫濱決戰剛結束、約第 85 話開始）。內嵌角色世界書，有 1 個預設開場與 3 個額外開場 | 角色管理 → 匯入 |
| [`[魔都精兵]角色_第85話.json`](%5B魔都精兵%5D角色_第85話.json) | 角色世界書：45 人（37 人的完整角色包＋8 名路人），645 條。和卡片內嵌的是同一本 | 世界書 → 匯入（只在不用卡片內嵌時需要） |
| [`[魔都精兵]世界觀_第85話.json`](%5B魔都精兵%5D世界觀_第85話.json) | 世界觀世界書：總覽、世界規則、索引，以及 15 個地點／勢力／制度／種族／事件，共 21 條 | 世界書 → 匯入 |

## 匯入步驟

1. 角色管理 → 匯入 `魔都精兵日常.json`。看到「要不要匯入內嵌世界書」時選確定，會建立並綁定「[魔都精兵]角色_第85話」。
2. 世界書 → 匯入 `[魔都精兵]世界觀_第85話.json`，再把它加到這個角色的額外世界書（或設成全域）。
3. 建一個使用者人設：
   - **取代優希**：人設名字取「和倉優希」，或在描述寫「取代和倉優希的位置」，然後用預設開場。
   - **不取代優希**：照你想要的身分寫人設。優希會變成 NPC。開場可以選額外開場 1～3。
4. 好感度插件的初始值、劇情推演的故事設定、原作接下來的事件（可當伏筆），都寫在卡片的「作者備註」（creator_notes）裡。
