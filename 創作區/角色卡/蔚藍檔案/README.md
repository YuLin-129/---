# 蔚藍檔案

《蔚藍檔案》的角色總表。格式照 [`../角色總表_寫作說明.md`](../角色總表_寫作說明.md) 與 [`../角色總表_模板.json`](../角色總表_模板.json)。

## 兩個版本

| 版本 | 內容 | 狀態 |
| --- | --- | --- |
| **總表**（這個資料夾） | 角色的完整資料，最大還原。主線、活動、羈絆、社團、迷你劇情都寫進去，包括後來才發生的事；`meta.story_time`、`now`、`knowledge.cutoff` 寫到目前實裝的最新進度 | 製作中 |
| 和劇情切開的版本 | 從總表導出：不寫主線事件，以日常與角色本人的資訊為主，和主線系統分開 | 之後再做 |

## 寫法約定

- 檔名：`角色總表_角色全名.json`（例如 `角色總表_空崎陽奈.json`）。
- 泳裝、正月、禮服等版本視為同一個人：寫進同一份總表，衣裝放在 `appearance.outfits`，各版本的羈絆劇情一起當資料來源。
- 資料來源以 `創作區/` 裡的劇情原文為主：`01_主線劇情`、`02_特殊作戰`、`03_活動劇情`、`04_羈絆劇情`、`05_社團劇情`、`06_迷你劇情`、`08_其他`；`00_實裝順（主線・Ex）` 和 `01`、`02` 內容重複，不另外引用。官方檔案數據（年齡、身高、興趣、武器、聲優）另查並在 `meta.sources` 寫出處。
- [`../../參考/blue_archive_kivotos_worldbook_zhTW.json`](../../參考/blue_archive_kivotos_worldbook_zhTW.json) 的人物條目只當整理參考，內容要和劇情原文對過才採用。
- 劇情原文是日文的（國際服尚未推出的部分），引用時自行翻譯，並在 `meta.divergence` 註明。
- 身高與三圍：每份總表都要有（規則見 [`../角色總表_寫作說明.md`](../角色總表_寫作說明.md) §2.3「身高與三圍」）。官方檔案只公開身高，所以學生（多為未成年）的三圍寫「官方未公開」，不依圖推測；成年角色（老師、黑色西裝人、凱薩集團等）依立繪推測並寫明看了哪些圖。

## 路人與背景人物

戲份少、沒有自己故事線的角色，不寫總表，照 [`../角色分級_寫作說明.md`](../角色分級_寫作說明.md) 寫成世界書條目（格式同 [`../角色分級_模板.json`](../角色分級_模板.json)，可以直接匯入 SillyTavern）：

- **路人**：一條 `［全名・名片］`，sticky 2。
- **背景人物**（沒有名字的士兵、學生、守衛……）：不寫個人，寫進地點條目 `地點｜［地點名］` 的「這裡常見的人」，每個地點最多三群。
