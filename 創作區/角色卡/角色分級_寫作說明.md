# 配角、路人、背景人物：角色卡寫作說明
> 撰寫：claude-fable-5-1（effort high）・2026-10-25

> 用法：寫新角色時，先用第 1 節判斷他是哪一級，再照那一級的範本填；填完用第 6 節的檢查表看一遍。要交給 AI 寫時，把這份說明、`角色分級_模板.json`（空白骨架，6 條：配角的核心／關係／情境／私密、路人的名片、地點）和第 5 節的範例一起給它。
> 模板直接匯入世界書就能用：把「配角全名」「對象全名」這類占位的詞換掉、填內容、不要的條目刪掉；關鍵字邏輯、sticky、掃描深度都已經設好。
> 主要角色不在這份裡：照 `docs/19_角色卡與世界書條目格式設計.md` §4.1～4.10 與 `姬絲秀忒_角色包.md`。分級的理由見 docs/19 §4.11。

---

## 1. 先判斷是哪一級

| 級 | 他是誰 | 兩個問題 | 誰演他 |
|---|---|---|---|
| **主要角色** | 故事的核心，有自己的弧線、秘密，會長期改變 | — | 自己的 NPC 節點 |
| **配角** | 反覆登場、**有自己想要的東西**、會影響劇情走向；但故事不是關於他 | 他不在了，故事會少一條線嗎？**會** | 寫手；群戲排到他時由群戲演 |
| **路人** | 有名字、有固定位置（店家、櫃檯、守門的），可能常見到，但不推動劇情 | 換成另一個同職業的人，玩家會發現嗎？**會** | 寫手 |
| **背景人物** | 沒有名字的人、一群人（酒館常客、衛兵、商隊） | 換掉也不會發現 | 寫手，從地點條目裡挑 |

拿不準就往下寫一級。往下寫少了，之後補得回來；往上寫多了，每回合都在付 token，而且寫手會拿多出來的設定硬演。

**升級**：路人被玩家在意起來（常去找他、捲進事件）→ 加一條核心，變配角。配角變成故事核心、要自己的 NPC 節點 → 補範例台詞、守則、視野、私密，變主要角色。原有條目不用重寫，名稱也不用改。

## 2. 配角

### 2.1 條目一覽

| 條目 | 必要 | 主要關鍵字 | 次要關鍵字 | 其他設定 | 長度 |
|---|---|---|---|---|---|
| `［全名・核心］` | 必要 | 全名、常用稱呼（2～4 個） | 無 | sticky 3 | ≤ 400 token |
| `［全名×對象］` | 只寫重要的 1～3 人 | **對方**的名字、稱呼 | 他的全名、稱呼；邏輯「且含任一」 | 掃描深度 2 | 每條 ≤ 200 |
| `［全名・情境描述］` | 0～2 條，只寫一定會碰到的事 | 情境詞（錨點，少而具體） | 他的全名、稱呼；「且含任一」 | 掃描深度 1 | 每條 ≤ 200 |
| `［全名・私密］` | 有秘密才寫 | 全名、稱呼 | 無 | sticky 3 | ≤ 150 |

一個配角總共 2～6 條，在場時約 400～900 token。

**不寫**：獨立的範例台詞、守則（角色備註）、視野、五大人格、「三個反差」、經歷年表。需要的一兩句直接放進核心。

### 2.2 核心的八行

每一行一到三句。順序固定：先讓寫手認得他，再知道他要什麼，最後是界線（尾端最容易被記住）。

```
名字：全名（別人怎麼叫他）。
定位：身分＋他和這個故事的關係，一句。
外觀：一句，挑最容易認出他的特徵。
個性：表面一句；底下一句——他為什麼這樣（一件過去的事或一個在意的人）。
說話：語氣、自稱與稱呼；一句代表台詞。
想要：他現在最想要的事、最在意的事。
對主角：目前的看法；還沒見過面就寫他聽過什麼、第一印象會是什麼。
界線：他不會做的事，正面寫、附理由。
```

逐行的要求：

- **定位**裡要有「和這個故事的關係」：他是委託人、受害者的家人、情報來源、對手……沒有這一句，寫手不知道該什麼時候讓他出現。
- **個性**的「底下」只寫一件事。配角不需要完整的心理結構，一個理由就足夠讓他的反應一致。
- **說話**的代表台詞是給寫手抓語氣的，不是名言；寫他平常真的會說的那種話。
- **想要**是配角和路人的分界。有「想要」，他才會主動找主角、才會拒絕、才會討價還價，寫手也才有理由讓他自己開口，而不是等主角搭話。寫**現在**的想要，不寫人生目標。
- **對主角**寫的是**開場時**的看法；之後的變化交給好感度插件的「她對主角的看法」與記憶，這一行不用回頭改。
- **界線**正面寫：「不丟下隊友先逃——她這輩子只做過一次，不會再做第二次」，不寫「不會背叛」這種空話。

### 2.3 關係條目

只寫對劇情有用的關係：家人、隊友、上司、宿敵。一條 100～200 token：

```
〔對方〕是他的〔關係〕。他怎麼看對方（一句）；兩人相處的樣子（一句）；一個只有他們之間才有的細節。
稱呼：他怎麼叫對方。〔可選：對方在場時他會變成什麼樣子。〕
```

關鍵字倒過來設：主要關鍵字放**對方**的名字（錨點），次要放**他自己**的名字（限定詞），「且含任一」——談到對方、而且他也在，才送。

### 2.4 情境條目

只寫「一定會碰到、而且他的反應和一般人不一樣」的事。例如被問到失蹤的妹妹、有人想買他不賣的東西。一般的反應（被誇、被罵、被威脅）不用寫，寫手照核心演得出來。

關鍵字照 docs/19 §4.5.1：主要關鍵字是情境詞（錨點，2～5 個），次要關鍵字是他的名字，「且含任一」，掃描深度 1（只看玩家這回合的話，不然上一則敘事裡的詞會讓條目多留一回合）。

### 2.5 私密條目

他知道但不說的事、他在隱瞞的事。只在這件事會影響劇情時寫；名稱裡一定要有「私密」兩個字（NPC 節點只收自己的私密；寫手照常收到整本）。配角由寫手演，所以寫手看得到——這是正常的，寫手需要知道他在藏什麼才演得出「藏」。

## 3. 路人

一條 `［全名・名片］`，80～150 token。主要關鍵字＝全名＋他的地方或職稱（例如「雅莉」「乾貨行」），sticky 2。

```
全名（別人怎麼叫他）：身分與所在的地方。外觀一句。說話一句。他會做的事（他的功能）。一個讓人記得的小習慣或口頭禪。
```

- **功能**就是玩家找他做什麼：賣東西、蓋章、開門、傳話。寫手靠這個決定他能幫到哪裡。
- **小習慣或口頭禪**是讓玩家記得他的東西，一個就夠。
- 不寫想要、不寫關係、不寫過去。他和主角的互動到「他的工作」為止；寫手可以照情境補普通的反應（被殺價會皺眉），但不會替他生出劇情。
- 關鍵字裡放他的地方或職稱，是因為玩家常常不記得路人的名字，只會說「去乾貨行」。

---

## 4. 背景人物

不寫角色條目。寫進**地點**條目的「這裡常見的人」，一到三句：

```
標題：地點｜［地點名］        ← 括號裡不能有「・」或「×」，否則引擎會把它當成角色
關鍵字（進階條件）：(地點名|別稱) | ((這類地方的通稱…) & (上層地點名…)［最近 4 則］)
                                ← 通稱（旅店、酒館）要有上層地點限定，見 世界觀總表_寫作說明.md §4
內容：
（地點本身的描述……）
這裡常見的人：〔哪些人、什麼時候、在做什麼〕；〔第二群〕；〔固定會在的無名人物，例如跑堂的兩個少年〕。
```

- 寫**類型與狀態**，不寫個體：「傍晚以後坐滿下迷宮回來的冒險者，嗓門大、愛賭骰子」。寫手需要時從這裡挑一個人寫幾句，不替他取名。
- 玩家開始反覆找同一個人（「上次那個喝悶酒的礦工」），再升成路人、給他名字。
- 一個地點的「常見的人」不超過三群，多了寫手會每一群都寫一遍。

## 5. 範例（峽谷城巴斯庫拉）

### 配角：莉瑟拉

```
標題：［莉瑟拉・核心］
主要關鍵字：莉瑟拉、三尾的隊長、蛇眼　　sticky 3
名字：莉瑟拉（冒險者都叫她「隊長」或「蛇眼」）。
定位：女性冒險者隊伍「三尾」的隊長，蛇眼族劍士，B 級；在巴斯庫拉帶隊下迷宮五年。
外觀：細長的豎瞳、左臉頰到脖子有一片淡青色的鱗；高瘦，總是穿著補了又補的皮甲。
個性：冷靜、嘴硬、凡事先算風險；底下是怕再失去隊友——她以前的隊伍在迷宮第六層全滅過，只有她回來。
說話：短句、不客套，自稱「我」，叫人只叫名字或「喂」。「要謝就把報酬分清楚，別的免了。」
想要：讓「三尾」的兩個隊員活著升上 A 級；在那之前不接超過能力的委託。
對主角：沒見過面；聽說過「帶著小孩下迷宮的人族魔術師」，覺得是個不要命的怪人。
界線：不丟下隊友先逃——她這輩子只做過一次，不會再做第二次。
```

```
標題：［莉瑟拉×杜爾克］
主要關鍵字：杜爾克、老哥　　次要關鍵字：莉瑟拉、蛇眼　　且含任一　　掃描深度 2
杜爾克是她的哥哥，在迷宮裡失去一隻手臂後退休。她嘴上嫌他囉唆、愛操心，每個月卻固定把一部分報酬塞進他的門縫，從不當面給。
稱呼：老哥。被他當面關心時會轉移話題。
```

```
標題：［莉瑟拉・被問到全滅的舊隊伍］
主要關鍵字：第六層、以前的隊伍、全滅、舊隊友　　次要關鍵字：莉瑟拉、蛇眼、隊長　　且含任一　　掃描深度 1
被問到以前的隊伍：先沉默一拍，然後用最少的字講完事實（五個人下去，她一個人上來），不講細節、不接受安慰。追問的話她會起身走開。只有在對方也失去過同伴時，她才會多說一句：「活著的人要把報酬分清楚。這是我學到的全部。」
```

### 路人：雅莉

```
標題：［雅莉・名片］
主要關鍵字：雅莉、乾貨行　　sticky 2
雅莉（乾貨行的小老闆）：崖頂區唯一賣仙人掌果蜜的乾貨行老闆，蛇尾魔族的年輕女性，尾巴總是纏在櫃台腳上。說話甜、算盤更快，「這罐是今天最後一罐了喔」是她的口頭禪（其實後面還有）。很會看客人的臉色喊價；記得每個常客愛買什麼。
```

### 背景人物：寫在歪角亭裡

```
標題：地點｜［歪角亭］
關鍵字（進階條件）：(歪角亭) | ((旅店|客棧|食堂|老闆娘) & (巴斯庫拉|峽谷城|瑪姬達)［最近 4 則］)
棧道區的旅店兼酒館，二樓是客房，老闆娘是獨角族的瑪姬達。這裡常見的人：傍晚以後坐滿下迷宮回來的冒險者，嗓門大、愛賭骰子；角落常有喝悶酒的老礦工；跑堂的是兩個獨角族少年，老闆娘的姪子。
```

## 6. 檢查表

寫完每個角色看一遍：

- [ ] 級別對嗎？用第 1 節的兩個問題再問一次。
- [ ] 條目名稱是 `［全名・類型］` 或 `［全名×對象］`，同一個人每條都用**同一個全名**（docs/19 §4.10）。
- [ ] 地點條目的括號裡**沒有**「・」「×」。
- [ ] 核心八行都有，而且「想要」寫的是**現在**的事。
- [ ] 界線是正面寫、附理由，不是「不會背叛」「不會說謊」。
- [ ] 關係條目的主要關鍵字是**對方**的名字，次要才是他自己。
- [ ] 情境條目掃描深度 1；主要關鍵字沒有超過 5 個。
- [ ] 沒有寫「不得」「禁止」「絕不」開頭的句子（要就改成他會怎麼做）。
- [ ] 總長度：配角 ≤ 900、路人 ≤ 150。
- [ ] 全部是繁體中文、台灣用語。

常見的錯：

| 錯 | 為什麼 | 改成 |
|---|---|---|
| 給路人寫「想要」 | 寫手會讓他主動找主角、生出支線 | 刪掉；要有事就升成配角 |
| 配角的核心寫了完整經歷 | 每回合都在付 token，寫手會拿來硬演 | 只留「底下」那一件事；其他的，劇情碰到了再用記憶插件記 |
| 關係條目的主鍵放自己的名字 | 他一在場就送，等於常駐 | 主鍵放對方、次要放自己 |
| 「對主角」寫成會變的東西（「漸漸信任他」） | 條目不會自己更新，之後就和實際劇情打架 | 只寫開場的看法 |
| 背景人物取了名字 | 有名字就會被當成角色反覆寫 | 寫類型；被玩家記住再取名 |
