# 世界書

把 `角色卡/` 的角色總表做成世界書時用的設定與時間點調整。產出放在 [`輸出/`](../輸出/)。

## 魔都精兵（第 85 話）

角色總表的時間點是第 149～150 話。這份世界書是給從第 85 話（橫濱決戰剛結束）開始的日常卡用的，所以每個人都另外寫了調整檔，把關係、經歷、知道的事、現況改回第 85 話，不洩漏之後的劇情。

| 檔案 | 內容 |
| --- | --- |
| [`魔都精兵/角色世界書設定.json`](魔都精兵/角色世界書設定.json) | 書名、要收哪些人（總表＋調整檔）、名字含「・」的人的短稱、路人名片 |
| [`魔都精兵/第85話調整/`](魔都精兵/第85話調整/) | 29 位有總表的角色的第 85 話調整檔。有 `lore` 區塊，定義在場判斷詞、名片、守則、關係對象的稱呼 |
| [`魔都精兵/配角/`](魔都精兵/配角/) | 沒有總表的 8 人（青羽、可可、波音、佐原、銀奈、理宇、惠美、夢路），用和調整檔一樣的格式直接寫 |

調整檔會和總表做深度合併：物件逐欄合併，清單整個替換，值是 `null` 的欄位會刪掉。完整說明在 [`工具/總表轉世界書.py`](../工具/總表轉世界書.py) 開頭。

## 重新產生

在 `創作區/` 底下執行：

```sh
python3 工具/總表轉世界書.py 世界書/魔都精兵/角色世界書設定.json "輸出/[魔都精兵]角色_第85話.json"
python3 工具/世界觀總表轉世界書.py 世界觀/世界觀總表_魔都精兵.json "輸出/[魔都精兵]世界觀_第85話.json"
python3 工具/內嵌世界書.py 角色卡/旁白卡_魔都精兵日常.json "輸出/[魔都精兵]角色_第85話.json" "[魔都精兵]角色_第85話" 輸出/魔都精兵日常.json
```

| 工具 | 作用 |
| --- | --- |
| `總表轉世界書.py` | 角色總表 → B 世界書版的角色包。條目包括名片、核心、公開印象、範例台詞、守則、關係、情境、經歷、能力、外觀、喜好、視野、私密。觸發用進階條件（`extensions.rp_conditions`），同時把條件編成正則主要關鍵字，讓酒館也能讀 |
| `世界觀總表轉世界書.py` | 世界觀總表 → 世界書。常駐總覽、世界規則、索引；每個實體各一條觸發條目，有真相的實體另加一條「真相」條目（加 `--no-truth` 就不產生） |
| `內嵌世界書.py` | 把世界書轉成酒館角色卡的 `character_book` 格式，再內嵌進卡片 |
