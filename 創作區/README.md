# 創作區

角色卡與世界觀設定的工作區域。

| 資料夾 | 用途 |
| --- | --- |
| [`角色卡/`](角色卡/) | 每個角色一份角色卡 |
| [`世界觀/`](世界觀/) | 世界觀、地點、勢力、名詞等設定 |

## 使用方式

1. 複製對應資料夾中的 `_範本_*.md`，改成新檔名後再填寫。
2. 檔名建議：角色卡用角色名稱（例：`林小雨.md`），世界觀依主題命名（例：`地理.md`、`勢力.md`）。
3. 圖片素材仍放在根目錄（`cg*.png`）、`half/`、`BG/`，在設定檔中以相對路徑引用即可，例如 `../../half/cg001_half.png`。
