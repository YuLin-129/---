# 創作區

角色卡與世界觀設定的工作區域。做法是：先把調查結果寫成完整的**總表**（JSON，最大還原、不直接送模型），要用時再**導出**成角色包、世界書條目等。

| 資料夾 | 用途 |
| --- | --- |
| [`角色卡/`](角色卡/) | 角色總表（主要角色）、角色分級（配角／路人／背景人物） |
| [`世界觀/`](世界觀/) | 世界觀總表：總覽、地點、勢力、制度、文化、種族、事件、物品、前提 |
| [`世界書/`](世界書/) | 把總表做成世界書時用的設定、時間點調整檔，以及重新產生的方法 |
| [`工具/`](工具/) | 總表 → 世界書、世界書內嵌進角色卡的腳本 |
| [`輸出/`](輸出/) | **可以直接匯入 RP Engine 的檔案**（角色卡、世界書），由工具產生 |
| [`主線/`](主線/) | RP 引擎的主線檔（開放世界的劇情時間表）、模板與寫作說明 |
| [`docs/`](docs/) | 研究與格式設計文件（各說明裡的 `docs/19` 等指的就是這裡） |
| [`參考/`](參考/) | 不照本區規範做的舊資料（例如蔚藍檔案角色卡草稿），只供查內容 |

## 從哪裡開始

- **寫角色**：先用 [`角色卡/角色分級_寫作說明.md`](角色卡/角色分級_寫作說明.md) 第 1 節判斷級別。
  - 主要角色 → [`角色總表_寫作說明.md`](角色卡/角色總表_寫作說明.md)＋[`角色總表_模板.json`](角色卡/角色總表_模板.json)，範例 [`角色總表_姬絲秀忒.json`](角色卡/角色總表_姬絲秀忒.json)
  - 配角、路人、背景人物 → [`角色分級_寫作說明.md`](角色卡/角色分級_寫作說明.md)＋[`角色分級_模板.json`](角色卡/角色分級_模板.json)
  - 其他完整範例：傑妮絲、提爾、阿妮斯（見 [`角色卡/README.md`](角色卡/README.md)）
- **寫世界觀**：[`世界觀/世界觀總表_寫作說明.md`](世界觀/世界觀總表_寫作說明.md)＋[`世界觀總表_模板.json`](世界觀/世界觀總表_模板.json)
- **直接拿去玩**：[`輸出/README.md`](輸出/README.md) 有匯入步驟（目前有《魔都精兵的奴隸》第 85 話的日常卡＋角色、世界觀世界書）
- **交給 AI 寫**：把對應的寫作說明、模板、範例一起給它。

## 命名

- 新角色：`角色總表_角色全名.json`
- 新世界觀：`世界觀總表_世界或地區名.json`
- 圖片素材仍放在根目錄（`cg*.png`）、`half/`、`BG/`；推測身高三圍時在 `appearance.measurements_source` 寫明看了哪些圖。
