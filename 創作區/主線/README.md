## 《魔都精兵的奴隸》第一章

- **不預設主角**：玩家的角色由開場決定；和倉優希不一定出場，玩家可能取代他的位置。原作裡屬於優希的事件，由在場、有理由的人承接。
- **錨定日**：第 1 天＝上野毛的突發門。不介入時的時間表寫在 `truths.timeline`。
- **毀滅的起點**：A 京香倒下；B 七番組寮失守或七番組被解散；C 和倉青羽被八雷神擄走；D 人型醜鬼與魔防隊全面開戰。
- **名字**：照本資料夾 `角色卡/` 的繁體譯名（羽前京香、東日萬凜、和倉青羽……）。世界書條目用別的譯名時，要改成一致。
